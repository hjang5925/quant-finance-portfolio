# ETF Analyzer

## Overview

This project analyzes and compares the performance of three popular exchange-traded funds (ETFs):

- VOO (Vanguard S&P 500 ETF)
- VTI (Vanguard Total Stock Market ETF)
- QQQ (Invesco NASDAQ-100 ETF)

The goal is to evaluate investment performance using both return and risk metrics.

---

## Features

- Historical ETF price retrieval
- Total return calculation
- Annualized volatility calculation
- Sharpe Ratio analysis
- Performance visualization

---

## Technologies Used

- Python
- Pandas
- Numpy
- Matplotlib
- yfinance
