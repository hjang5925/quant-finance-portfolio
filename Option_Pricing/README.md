# Option Pricing

## Overview

This project implements several core option pricing concepts used in quantitative finance and financial engineering.

The objective is to estimate option values and analyze option risk using both analytical and simulation-based methods.

---

## Features

- Black-Scholes Option Pricing
- Delta Calculation
- Gamma Calculation
- Vega Calculation
- Theta Calculation
- Monte Carlo Option Pricing

---

## Files

### black_scholes.py

Calculates the theoretical price of a European call option using the Black-Scholes model.

### delta.py

Calculates Delta, measuring sensitivity to stock price changes.

### gamma.py

Calculates Gamma, measuring sensitivity of Delta.

### vega.py

Calculates Vega, measuring sensitivity to volatility.

### theta.py

Calculates Theta, measuring time decay.

### monte_carlo_option.py

Estimates option value using Monte Carlo simulation.
